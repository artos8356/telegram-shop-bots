# Бот-магазин

Telegram-бот, через который продавец одежды принимает заказы без переписки вручную.

## Что умеет

**Для покупателя**
- каталог с фото, ценой, замерами, состоянием и материалом;
- оформление заказа: данные для доставки одним сообщением, оплата по реквизитам, фото чека;
- сообщение о том, подтверждена оплата или нет;
- кнопки «Отзывы» и «Поддержка».

**Для продавца** (команды видит только он)
- `/additem` — добавить товар по шагам;
- `/listitems`, `/removeitem` — список товаров и удаление с подтверждением;
- заявка о каждом заказе с чеком и кнопками «Подтвердить» / «Отклонить»;
- `/stats` — продажи за день, неделю и всё время, топ покупателей;
- `/broadcast` — рассылка покупателям с отчётом о доставке;
- `/export` — скачать базу;
- `/restart` — перезапустить бота.

## Главная логика

Вещь считается проданной только после того, как продавец подтвердит оплату. До этого заказ «ждёт подтверждения», а на каждом шаге бот проверяет, не купил ли эту вещь кто-то другой. Так одну вещь невозможно продать дважды.

База данных (SQLite): товары, заказы со статусами и покупатели. Раз в сутки бот сам делает резервную копию базы и хранит 14 последних.

## Запуск

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp config.example.json config.json   # и заполнить своими данными
venv/bin/python bot.py
```
