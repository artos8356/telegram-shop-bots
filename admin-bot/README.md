# Админ-бот: учёт клиентов и подписок

Мой рабочий инструмент. Клиенты платят за своих ботов по подписке, а этот бот хранит, кто, за какого бота и до какого числа заплатил.

## Что умеет

**Для всех**
- «Наши клиенты» — список магазинов, для которых сделаны боты;
- «Сделать бота» — контакт для заказа;
- «У меня уже есть бот» — клиент видит своих ботов, до какого числа оплачено и реквизиты.

**Для меня** (команды видит только администратор)
- `/addclient`, `/addbot` — добавить клиента и его бота (у клиента может быть несколько ботов);
- `/pay` — отметить оплату, бот сам посчитает следующую дату;
- `/status` — все клиенты, сроки и просрочки одним списком;
- `/removebot`, `/removeclient`, `/bind`, `/restart`.

## Главная логика

- День оплаты запоминается при первой оплате. Если клиент платит вовремя, срок продлевается от даты окончания, если с опозданием — от даты оплаты. Месяцы разной длины учитываются (31-е число превращается в 28-е или 30-е).
- Каждый день бот проверяет сроки и за 3 дня до окончания пишет клиенту, а мне присылает копию. Одно и то же напоминание не отправляется дважды.
- Клиент привязывается к своей записи по Telegram ID автоматически, без кодов доступа.

База данных (SQLite): две таблицы — клиенты и их боты. При обновлении старая база переносится в новую схему автоматически.

## Запуск

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp config.example.json config.json   # и заполнить своими данными
venv/bin/python bot.py
```
