# Telegram-боты для небольших магазинов

Два бота, которые я сделал и поддерживаю для своих клиентов — продавцов одежды в Telegram и на Авито. Боты работают на моём сервере, у каждого клиента свой экземпляр.

| Бот | Для кого | Что делает |
|---|---|---|
| [shop-bot](shop-bot/) | Покупатели и продавец | Магазин в Telegram: каталог, заказ, оплата по чеку, статистика для продавца |
| [admin-bot](admin-bot/) | Я и мои клиенты | Учёт клиентов и подписок на ботов, напоминания об оплате |

**Технологии:** Python, python-telegram-bot, SQLite, Linux (Ubuntu), systemd.

## Как устроено

- Код один, а настройки (токен, название магазина, реквизиты) у каждого клиента свои — в файле `config.json`. Поэтому новый магазин запускается без изменения кода.
- Каждый бот работает как отдельный сервис на сервере и сам перезапускается после сбоя. Пример настройки: [deploy/bot@.service](deploy/bot@.service).
- Токены, реквизиты и базы данных в репозиторий не попадают: вместо них лежат примеры `config.example.json`.
